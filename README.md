## 🔥 本周热门话题速览（2026年8月第33周）

1. **夏季皮肤护理**：湿疹 vs 痱子区分（一片片 vs 一粒粒）、正确用药
2. **宝宝吹空调指南**：温度26-28℃、风向向上、室内外温差≤8℃
3. **4月龄睡眠倒退破解**：接觉技巧、白天小睡规律、避免过度干预
4. **出牙期全攻略**：冷敷牙胶、牙龈按摩、口水疹预防
5. **翻身期安全**：床边围栏、床下地垫、不要独处床上

## ⚠️ 就医红线

以下情况请立即就医：

1. **3月龄仍不能抬头** — 大运动发育预警
2. **6月龄不能翻身/不会笑** — 发育迟缓信号
3. **高热≥38.5℃** 或持续低烧超过3天
4. **频繁喷射性呕吐** 或吐出咖啡色液体
5. **血便、柏油便** 或大便带脓
6. **抽搐、意识不清、哭声微弱**
7. **呼吸困难、嘴唇发紫**
8. **黄疸超过2周未消退** 或颜色加深
9. **前囟门隆起或明显凹陷**
10. **9月龄不能独坐/叫名无反应**
