## 🔥 本月热门话题速览（2026年8月底-9月）

1. **秋季换季护理**：入秋后温差变大，皮肤干燥、湿疹复发、秋季腹泻预防
2. **出牙期全攻略**：5个月是出牙高峰期，牙胶冷藏、牙龈按摩、口水疹护理
3. **5月龄睡眠倒退收尾**：4月龄睡眠倒退接近尾声，巩固接觉能力
4. **辅食添加倒计时**：观察宝宝是否已具备添加信号（靠坐稳、伸舌反射消失、对食物感兴趣）
5. **秋季疫苗规划**：流感疫苗（≥6月龄）、手足口疫苗、轮状病毒疫苗

## ⚠️ 就医红线

以下情况请立即就医：

1. **3月龄仍不能抬头** — 大运动发育预警
2. **6月龄不能翻身/不会笑** — 发育迟缓信号
3. **高热≥38.5℃** 或持续低烧超过3天
4. **频繁喷射性呕吐** 或吐出咖啡色液体
5. **血便、柏油便** 或大便带脓
6. **抽搐、意识不清、哭声微弱**
7. **呼吸困难、嘴唇发紫**
8. **黄疸超过2周未消退** 或颜色加深
9. **前囟门隆起或明显凹陷**
10. **9月龄不能独坐/叫名无反应**
