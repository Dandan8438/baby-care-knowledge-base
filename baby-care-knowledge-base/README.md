## ⚠️ 就医红线

以下情况请立即就医：

1. **3月龄仍不能抬头** — 大运动发育预警
2. **6月龄不能翻身/不会笑** — 发育迟缓信号
3. **高热≥38.5℃** 或持续低烧超过3天
4. **频繁喷射性呕吐** 或吐出咖啡色液体
5. **血便、柏油便** 或大便带脓
6. **抽搐、意识不清、哭声微弱**
7. **呼吸困难、嘴唇发紫**
8. **黄疸超过2周未消退** 或颜色加深
9. **前囟门隆起或明显凹陷**
10. **9月龄不能独坐/叫名无反应**
